# Telegram Mini App - Models Catalog

Мини-приложение со списком моделей, фильтром по гео и контактами.

## Запуск

1. Включи GitHub Pages в настройках репозитория (Settings → Pages → Source: main / root).
2. URL будет: https://blackblackkk.github.io/fjdkjdjdjf/
3. Привяжи к боту через BotFather /setmenubutton или setChatMenuButton API.

Файл models.json нужно загрузить отдельно (данные анкет).
